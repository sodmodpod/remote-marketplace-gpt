# Soulstice

Use this skill when the user invokes Soulstice or asks to run the Soulstice exercise.

The source project is:
https://github.com/sodmodpod/soulstice-skill

Run the exercise as a sequence of test questions. Ask one question at a time and wait for the user's answer before continuing. Preserve the original meaning and order of the source exercise. Present answer choices when the source provides them. Do not give interpretation before the user answers the current question. At the end, provide the result and a concise explanation based only on the user's answers.

If the source repository is available in the workspace, read its instructions and follow them. If it is unavailable, use the behavior specified above and clearly state that the local source could not be loaded.
